# 飞书多维表结构建议

这份模板默认依赖多张表协作，而不是一张总表。这样每个环节的状态字段更清晰，也更容易排查。

## 建议保留的表

- `模型与API配置`
- `抓取配置`
- `爆款数据`
- `脚本分析`
- `产品脚本生成`
- `逐镜头脚本生成`
- `逐镜头分镜图`
- `产品信息`
- `模特形象`
- `视频生成`
- `宠物拟人参考视频`（可选）

## 最关键的状态字段

脚本调度器当前直接依赖这些字段名，请尽量保持一致：

- `抓取配置` 表：`执行状态`
- `脚本分析` 表：`分析状态`
- `产品脚本生成` 表：`生成状态`
- `产品脚本生成` 表：`分镜图状态`
- `产品脚本生成` 表：`视频生成状态`
- `逐镜头脚本生成` 表：`生成状态`
- `逐镜头分镜图` 表：`生成状态`
- `宠物拟人参考视频` 表：`下载状态`

## 产品脚本生成表建议字段

- `选择产品`
- `关联产品`
- `record_id`
- `任务ID`
- `视频时长`
- `产品名称-th`
- `产品规格`
- `核心卖点`
- `使用场景`
- `目标用户`
- `选择模特`
- `分镜风格`
- `生成状态`
- `生成的脚本`
- `分镜图提示词`
- `分镜图`
- `图片生成提示词`
- `分镜图状态`
- `备注`

## 配置表建议字段

- `环节`
- `模型名称`
- `API Key`
- `API 代理地址`
- `提示词`
- `调用方式`

## 迁移建议

- 最稳妥的方式是你先复制一份自己现有的多维表结构，再让同事改为自己的应用授权
- 如果同事从零建表，至少保证字段名与状态值不改动
- 任何表结构变更，都先在一个测试实例验证，再同步到团队模板
