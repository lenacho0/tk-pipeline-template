# TikTok 多维表工作流最终方案与 Prompt 规范

> 更新时间：2026-04-20
> 适用范围：飞书多维表 TikTok 爆款分析 → 共性提炼 → 脚本生成 → 生图提示词 → 图生视频提示词 工作流

## 1. 总体架构

### 1.1 表职责

- 表0：环节配置表
  - 管理各环节模型、API 配置、系统提示词、schema/version
- 表1：视频素材表
  - 一条记录 = 一条视频素材
  - 支持 TikTok 链接 / 上传视频
  - 输出单视频分析结果
- 表2：爆款共性分析表
  - 一条记录 = 一组样本的共性分析任务
  - 输出共性结构、脚本公式、变量框架
- 表3：项目主表
  - 一条记录 = 一个创作项目
  - 关联共性分析、产品、模特、可选场景参考
- 表4：产品信息表
  - 产品真源
- 表5：模特信息表
  - 人物真源
- 表6：脚本执行总表
  - 一条记录 = 一条脚本
  - 承载结构化脚本、可读脚本、生图提示词、图生视频提示词、分镜图、分镜视频、局部重跑信息

---

## 2. 真源与引用规则

### 2.1 强真源

- 产品外观真源：表4 产品信息表
- 人物外貌真源：表5 模特信息表

### 2.2 场景策略

- 不建立独立场景表
- 项目表可选提供：
  - 场景参考图
  - 场景参考说明
- 默认情况下，场景主要由：
  - 目标市场本土化规则
  - 共性分析中的变量方向
  - 脚本中的场景描述
  - 提示词中的具体场景约束
 共同生成

### 2.3 各环节引用优先级

#### 脚本生成
1. 表2 共性分析结果
2. 表4 产品信息
3. 表5 模特信息
4. 表3 项目级目标市场
5. 表3 可选场景参考图/说明

#### 生图提示词生成
1. 产品表（产品真源）
2. 模特表（人物真源）
3. 项目级场景参考（可选）
4. 脚本 JSON 中的人物卡片 / 场景卡片 / 画质卡片
5. 当前镜头脚本

#### 图生视频提示词生成
1. 当前镜头最终确认的分镜图（唯一视觉真源）
2. 当前镜头脚本
3. 目标市场语言规则
4. 全片统一 voice profile

> 图生视频阶段不再直接引用图1/图2/图3。

## 3. 目标市场本土化场景规则

### 3.1 总原则
当用户指定目标市场时，场景选择、空间类型、生活物件、居住环境感、使用场景与人物活动方式，必须优先贴近该市场普通用户熟悉的真实生活语境，而不是只做语言本地化。

### 3.2 约束
- 场景不能只是“卧室 / 客厅 / 厨房 / 浴室”等抽象标签
- 必须通过可见细节体现本土化：
  - 空间尺度
  - 家具关系
  - 陈设方式
  - 生活用品组合
  - 地面/墙面/台面使用状态
  - 家庭环境感
- 不得堆砌旅游宣传片式、刻板印象化地域符号
- 场景必须服务产品使用逻辑、人物设定和镜头功能

## 4. 环节职责边界

### 4.1 表1：单视频分析
输入：单条视频
输出：结构化爆款拆解 JSON + Markdown 报告

### 4.2 表2：共性分析
输入：多条单视频拆解结果
输出：
- 共性传播机制
- 共性转化机制
- 共性脚本结构
- 通用脚本公式
- 变量清单
- 市场适配建议

> 不输出完整同款脚本。

### 4.3 表6：脚本生成
输入：
- 表2 共性分析结果
- 产品信息
- 模特信息
- 目标市场
- 可选项目级场景参考

输出：
- 结构化脚本 JSON
- 可读脚本 TEXT/Markdown
- 人物卡片
- 场景卡片
- 画质卡片
- 镜头级脚本

### 4.4 生图提示词生成
输入：
- 图1 产品图
- 图2 模特图
- 图3 项目级场景参考图（可选）
- 结构化脚本 JSON

输出：
- 每镜头生图提示词 JSON
- 可读生图提示词 TEXT/Markdown

### 4.5 图生视频提示词生成
输入：
- 最终确认的分镜图
- 结构化脚本 JSON
- 目标市场语言规则
- 统一 voice profile

输出：
- 每镜头图生视频提示词 JSON
- 可读图生视频提示词 TEXT/Markdown

## 5. Prompt 清单

当前已定稿的 Prompt 类型：

1. 表1：单视频分析最终 System Prompt
2. 表2：爆款共性分析最终 System Prompt
3. 表6：脚本生成最终 System Prompt（含目标市场场景本土化规则）
4. 生图提示词生成最终 System Prompt（含目标市场场景本土化规则）
5. 图生视频提示词生成最终 System Prompt

### 6.1 JSON_OUTPUT 核心字段
- title
- basic_info
- video_overview
- distribution_engine
- conversion_engine
- script_breakdown
- comment_prediction
- copy_decision
- one_sentence_summary

### 6.2 Markdown_OUTPUT
- 严格按爆款拆解报告模板输出
- JSON 为主输出，Markdown 为人工查看输出

---

## 7. 表2：共性分析 Prompt 核心输出结构

### 7.1 JSON_OUTPUT 核心字段
- summary
- sample_count
- platform
- target_market
- common_elements
  - distribution_patterns
  - conversion_patterns
  - script_patterns
- variables
- market_adaptation
- copy_guidance

### 7.2 TEXT_OUTPUT
严格只输出三个区块：
1. 共性元素和公式
2. 变量清单
3. 适配建议

> 不输出同款脚本。

---

## 8. 表6：脚本生成 Prompt 核心输出结构

### 8.1 JSON_OUTPUT 核心字段
- script_meta
- static_cards
  - character_card
  - scene_card
  - quality_card
- structure_summary
- shots[]
- final_cta
- notes

### 8.2 关键规则
- 一条记录 = 一条脚本
- 镜头级输出
- 镜头数建议 4-10
- 台词若存在目标市场，则使用目标市场语言 + 紧随中文翻译
- 场景卡片必须体现目标市场本土化生活语境

### 8.3 TEXT_OUTPUT
输出顺序：
1. 共性与变量说明
2. 人物卡片
3. 场景卡片
4. 完整脚本
5. 画质卡片

---

## 9. 生图提示词生成 Prompt 核心输出结构

### 9.1 输入原则
- 图1 = 产品真源
- 图2 = 人物真源
- 图3 = 项目级可选场景参考
- 若没有图3，则根据目标市场、产品、人物和脚本动态生成场景

### 9.2 JSON_OUTPUT 核心字段
- global_consistency
  - product_lock
  - character_lock
  - scene_lock
  - style_lock
- shots[]
  - brief
  - is_selfie
  - uses_product_ref
  - uses_character_ref
  - uses_scene_ref
  - prompt
  - negative_constraints

### 9.3 强规则
- 每个分镜只对应一条生图提示词
- 自拍镜头必须用统一英文前缀
- 场景描述禁止出现光线描写
- 固定后缀必须原样追加：
  - 无美颜，无景深，无滤镜，无补光灯，展示人物真实的皮肤纹理以及真实的环境。no text, no watermark, no subtitle
- 若存在目标市场，场景必须以自然生活细节体现本土化

---

## 10. 图生视频提示词生成 Prompt 核心输出结构

### 10.1 输入原则
- 当前镜头最终确认的分镜图 = 唯一视觉真源
- 不再直接引用图1/图2/图3

### 10.2 JSON_OUTPUT 核心字段
- voice_profile
- shots[]
  - brief
  - is_selfie
  - duration_sec
  - video_prompt
  - voice_block
  - audio_notes
  - safety_constraints

### 10.3 强规则
- 单镜头不超过8秒
- 一镜头 = 一主动作
- 自拍镜头必须使用统一英文前缀
- 所有人声镜头必须复用同一条英文 voice_profile
- 口播只保留目标市场语言
- 口播格式只能是：
  - 人物：xxx。
  - 画外音：xxx。
- 固定后缀必须原样追加：
  - no text, no subtitles, no watermarks
- 图生视频提示词中禁止出现图1/图2/图3或参考图1/2/3
