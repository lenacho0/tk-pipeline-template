# TikTok Bitable Workflow 项目当前真实进度与边界（2026-04-21）

## 1. 项目目标

目标是在当前真实飞书 Base `TK爆款共性生视频全流程` 中，建立一条**独立于旧 `tk_toolkit_dual` / 旧 tkpipeline** 的新链路，覆盖：

- 多版本脚本批次规划
- 单版本脚本生成
- 分镜生成
- 生图提示词生成
- 图生视频提示词生成
- 后续再决定是否继续纳入：单视频分析、共性分析、真正的图片/视频执行层

---

### 不做的事
- 不挂旧 `tk_toolkit_dual` 当正式入口
- 不复用旧 dispatcher 作为新链路的正式调度底座
- 不继续把旧项目缝补成新项目
- 不另起一套空白飞书 Base

### 要做的事
- 继续使用当前真实 Base
- 让代码适配真实表结构，而不是强迫表完全迁就代码
- 在 `tiktok_bitable_workflow/` 下独立维护代码
- 先做最小可运行链路，再逐段补前后半程
