# 模块 A：逐镜头流程质量控制

## A1. 一致性控制继续增强（优先级最高）
### 当前问题
- 主角一致性已有改善
- 其他人物仍可能漂移
- 场景与世界观连续性不够稳定

### 策略
采用“**默认单主角叙事；其他人物如非必要，不作为清晰可辨识角色出现**”的折中方案。

### 为什么这样做
- 保住同一条逐镜头图组内部的一致性
- 不依赖多角色锚点系统（当前阶段尚未建立）
- 不牺牲脚本策略差异化

### 说明
这不是让所有脚本变得一样，而是：
- 统一视觉身份（主角 / 产品 / 风格 / 环境世界观）
- 保留叙事差异（hook、痛点、产品出场时机、节奏、CTA）

### 实施方向
- 在 `shot_script_gen` prompt 中加入单主角叙事约束
- 在 `shot_storyboard` prompt 中加入“禁止新增明确配角 / 背景人物弱化”约束
- 在 `全局视觉锚点` 中加入人物数量与环境连续性约束

---

## A2. 主视觉锚图机制（P1）
### 目标
在逐镜头图片正式批量生成前，先生成一张“主视觉锚图”，再作为后续所有 shot 的强参考图。

### 作用
- 提升主角一致性
- 提升产品一致性
- 提升色调和世界观一致性

---

## A3. 逐镜头图片生成失败分类（P0）
### 目标
将 `003-3` 的失败区分为：
- 配置错误
- 素材缺失
- prompt 构造错误
- 模型返回空
- 上传飞书失败
- 写回失败
- 运行时 bug

### 作用
方便批量使用时快速定位问题，不再只是“失败”。
