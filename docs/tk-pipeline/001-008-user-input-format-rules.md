# 001-008 用户输入格式规则

> 适用 Base：企业母版-TK爆款视频全自动生产  
> 目的：约束用户在 001-008 表里需要填写的字段格式，避免解析失败、提示词拆错、后续生图/生视频跑偏。

## 通用规则

- `*AI参数JSON`：不会写就留空。要写必须是合法 JSON 对象，例如 `{"size":"1080x1920"}`；不要写中文说明、中文冒号、Markdown、数组顶层。
- `关联产品记录`、`选择模特`：必须用飞书关联字段选择记录，不要把 record_id 粘到普通文本里。
- 附件字段：图片、视频、Markdown 文件必须上传到对应附件字段，不要把本地路径、网盘链接或 file_token 粘到普通文本字段。
- 状态触发字段：必须选表格已有选项，例如 `待生成`、`待解析`、`待拆分`、`通过`；不要手打近似值。
- 口播文本：最终要进 TTS 或视频音频的口播，只放目标语言原文；中文翻译、镜头说明、审核备注不要混进最终口播字段。

## 001-多角色开头钩子

### 用户需要填写

- `任务名称`
- `输入脚本`
- `关联产品记录`
- `目标时长秒`
- `拆解状态=待生成`

### 格式规则

`输入脚本`没有硬性 Markdown 模板，但必须足够结构化。建议至少写清楚：

- 角色：每个角色是谁、身份/关系/功能。
- 冲突：事故或问题是什么，谁制造/发现问题。
- 救场：谁使用产品，产品如何介入。
- 画面：开头、转折、结尾分别看到什么。
- 产品动作：是否拿起、展示、喷洒、擦拭、对比等。
- 口播：如果有泰语/目标语言台词，直接写原文。

### 常见错误

- `输入脚本`为空会直接报错。
- 只写一句创意，模型容易拆不出角色、参考资产、关键帧。
- 产品动作没写清楚，会导致关键帧判断不到 `需要产品参考图=是`。

### 推荐输入模板

```md
任务：三角色事故救场短视频

产品：关联产品记录为准
目标单段时长：8 秒

角色：
- 角色A：发现问题的人，身份/外观/情绪
- 角色B：制造或放大问题的人/宠物
- 角色C：救场并使用产品的人

剧情：
1. 开头事故：具体画面、问题位置、角色反应
2. 救场动作：谁拿出产品，怎么使用
3. 结果反转：问题如何可视化解决，角色怎么反应

口播/对白：
- 角色A：目标语言台词
- 角色C：目标语言台词

画面要求：
- 9:16 竖屏，UGC 手机拍摄感
- 不要字幕、贴纸、水印
```

## 002-产品使用场景

### 用户需要填写

- `任务名称`
- `关联产品记录`
- `首尾帧文档` 或 `首尾帧文档附件`
- `目标时长秒`
- `拆分状态=待拆分`

### 格式规则

这是硬格式。每个场景必须使用：

- `## S01 场景标题`
- `### S01-1 首帧生图提示词`
- `### S01-2 尾帧生图 / 编辑提示词`
- `### S01-3 首尾帧图生视频提示词`

多场景继续写 `S02`、`S03`。代码会按标题正则拆分，不符合就失败。

### 可复制模板

````md
## S01 场景标题

### S01-1 首帧生图提示词
```text
首帧画面提示词。写清楚人物/宠物/环境/产品是否出现，以及静态画面构图。
```

### S01-2 尾帧生图 / 编辑提示词
```text
尾帧画面提示词。写清楚产品使用后发生了什么变化，和首帧有什么连续关系。
```

### S01-3 首尾帧图生视频提示词
```text
视频提示词。写清楚从首帧到尾帧的动作、镜头运动、声音/口播、禁止字幕水印。
```
````

### 常见错误

- 缺少 `## S01 场景标题`。
- 小节不是 `### S01-1/2/3` 格式。
- 小节标题没有“首帧 / 尾帧 / 视频”关键词。
- 单条拆分只允许 1 个场景；多场景要走批量拆分入口。

## 003-爆款视频复刻

### 用户需要填写

- `记录类型=文档任务`
- `任务名称`
- `脚本文档` 或 `脚本文档附件`
- `关联产品记录`
- `视频时长`
- `解析状态=待解析`

### 格式规则

没有硬性 Markdown 解析模板，但脚本文档要能被模型拆成参考资产和分镜。建议每个镜头包含：

- 时间段，例如 `0-3s`
- 画面描述
- 人物/宠物/环境
- 产品是否出镜
- 动作和镜头
- 口播原文
- 屏幕文字和中文理解分开写

`视频时长`可以写 `15s`、`20秒` 或数字；代码会提取第一个数字。

### 推荐输入模板

```md
视频时长：15s
风格：真实 UGC / 产品写实 / 宠物短视频

全局参考资产：
- 宠物：外观、体型、毛色、表情
- 环境：房间类型、问题位置、光线、家具
- 人物：身份、外观、情绪

镜头 1｜0-3s｜Hook
画面：
口播：
产品出镜：否/是
动作：
镜头：

镜头 2｜3-7s｜产品介入
画面：
口播：
产品出镜：是
动作：
镜头：

镜头 3｜7-15s｜结果/CTA
画面：
口播：
产品出镜：是
动作：
镜头：
```

### 常见错误

- `脚本文档`为空会直接失败。
- 只给成片口播，不给画面，容易拆不出分镜图提示词。
- 产品参考图应该来自 `关联产品记录`，不要把产品当成全局参考资产写进脚本。

## 004-故事板

### 用户需要填写

- `记录类型=母任务`
- `故事板文档正文` 或上传 `.md` / `.markdown` / `.txt` 到 `故事板Markdown附件`
- 可选：`关联产品记录`、`选择模特`、`上传产品图`、`上传模特图`、`上传参考图`
- `解析状态=待解析`

### 格式规则

这是硬格式。每个 Storyboard 必须有成对的：

- `Storyboard 01 Image Prompt:`
- `Storyboard 01 Video Prompt:`

编号必须一致。可以放在代码块里，代码会从代码块或全文中提取。

### 可复制模板

````md
```text
Storyboard 01 Image Prompt:
Time Range: 0-4s
图片提示词内容。写清楚 9:16、画面、产品、人物/宠物、环境、构图。
```

```text
Storyboard 01 Video Prompt:
视频提示词内容。写清楚动作、镜头、音频、口播、禁止字幕水印。
```

```text
Storyboard 02 Image Prompt:
Time Range: 4-8s
图片提示词内容。
```

```text
Storyboard 02 Video Prompt:
视频提示词内容。
```
````

### 常见错误

- 只有 Image Prompt，没有 Video Prompt。
- Image 和 Video 编号不一致。
- 附件不是 `.md`、`.markdown`、`.txt`。
- 文档正文和附件都为空。

## 005-多图N宫格

### 用户需要填写

- `记录类型=母任务`
- `输入模式`
- `宫格数量`
- `脚本内容`
- `关联产品记录`
- `方案生成状态=待生成`

### 格式规则

默认 `输入模式=文档直拆` 是硬格式。必须包含：

- 可选参考图提示词：`### 人物参考图提示词`、`### 宠物参考图提示词`、`### 环境参考图提示词`
- 每个 Board 的图片提示词：`## Board 01 宫格分镜图提示词`
- 每个 Board 的视频提示词：`## Board 01 图生视频提示词`
- 图片提示词内部必须有 `Cell 1:`、`Cell 2:` ...，数量必须等于 `宫格数量`

只支持 `4宫格`、`6宫格`、`8宫格`、`9宫格`。

### 可复制模板

````md
### 人物参考图提示词
```text
单人正面半身白底参考图提示词。没有人物可不写。
```

### 宠物参考图提示词
```text
宠物全身身份参考图提示词。没有宠物可不写。
```

### 环境参考图提示词
```text
无人、无宠物、无产品的环境参考图提示词。只写房间、家具、问题位置、光线。
```

## Board 01 宫格分镜图提示词
```text
Create one vertical 9:16 image containing exactly 4 panels arranged in a 2x2 storyboard grid.
Cell 1: ...
Cell 2: ...
Cell 3: ...
Cell 4: ...
```

## Board 01 图生视频提示词
```text
0-8s vertical 9:16 TikTok UGC video. Follow Cell 1 to Cell 4 in order. Preserve product/package identity from references. No subtitles, no watermarks.
```
````

### 常见错误

- `脚本内容`为空。
- `宫格数量`选择 4，但文档里写了 6 个 `Cell`。
- 有 `Board 01 宫格分镜图提示词`，但缺 `Board 01 图生视频提示词`。
- `Cell` 写成中文“第1格”而不是 `Cell 1:`，代码可能识别不到。

## 006-视频编辑

### 用户需要填写

- `任务名称`
- `源视频`
- `编辑指令`
- 可选：`参考图`
- `输出分辨率`
- `音频策略`
- `编辑状态=待生成`

### 格式规则

- `源视频`必须上传视频附件。
- `编辑指令`不能为空，写自然语言即可。
- `参考图`最多取前 5 张。
- `输出分辨率`只能选 `720P` 或 `1080P`。
- `音频策略`只能选 `保留原音频` 或 `自动处理音频`。

### 推荐输入模板

```md
请基于源视频做以下编辑：
1. 保持主体人物/宠物/产品一致。
2. 将开头 2 秒加强为更明显的产品使用前问题。
3. 中段保留产品动作，不改变包装外观。
4. 结尾强化使用后结果和 CTA。
5. 不要加字幕、贴纸、水印，不要改变原视频比例。
```

## 007-口播音频生成

### 用户需要填写

- `文案标题`
- `文案`
- `选择音色` 或 `音色ID`
- `生成状态=待生成`

### 格式规则

- `文案`不能为空。
- `文案`必须是最终要朗读的内容，不要混入中文翻译、镜头说明、括号备注。
- 如果使用 `选择音色`，关联音色记录必须已有 `Voice ID`，且音色 `生成状态=成功`。
- 文件名会用 `文案标题`生成，标题不要包含特殊路径字符。

### 推荐输入模板

```text
นี่คือข้อความเสียงสุดท้ายที่จะให้อ่านจริง
อย่าใส่คำอธิบายฉากหรือคำแปลภาษาจีนในช่องนี้
```

## 008-产品展示CTA

### 用户需要填写

- `任务名称`
- `生图提示词`
- `图生视频提示词`
- 可选：`关联产品记录`、`选择模特`、`上传产品图`、`上传模特图`、`上传参考图`
- `图片生成状态=待生成`
- 图片审核通过后：`图片审核状态=通过`、`视频生成状态=待生成`

### 格式规则

- `生图提示词`不能为空。
- `图生视频提示词`不能为空。
- 参考图总数最多 7 张，包括产品表图片、上传产品图、模特图、上传参考图。
- 视频阶段必须先有 `生成图片`，且 `图片审核状态=通过`。
- `视频时长秒`填数字即可，例如 `8` 或 `10`。

### 推荐输入模板

```md
生图提示词：
Create a vertical 9:16 TikTok product CTA image. Show the product clearly in hand, natural UGC phone photo style, local home background, realistic lighting, no subtitles, no stickers, no watermark.

图生视频提示词：
Generate an 8-second vertical 9:16 product CTA video from the image. The hand naturally presents the product to camera, slight handheld motion, product package stays consistent with reference, natural room tone, no subtitles, no labels, no watermark.
```

### 常见错误

- 图片没审核通过就触发视频，会报 `图片审核状态必须为通过`。
- 没有生成图片就触发视频，会报缺少已生成图片。
- 参考图超过 7 张会报数量超限。

## 最容易出错的表

1. `002-产品使用场景`：严格依赖 `## S01` + `### S01-1/2/3`。
2. `004-故事板`：严格依赖 Storyboard Image/Video Prompt 成对编号。
3. `005-多图N宫格`：严格依赖 Board 标题和 `Cell N:` 数量匹配。
4. `008-产品展示CTA`：视频必须在图片审核通过后才能触发。
