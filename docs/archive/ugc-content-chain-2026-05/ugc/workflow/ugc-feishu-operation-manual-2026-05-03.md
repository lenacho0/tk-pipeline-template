# UGC 飞书多维表格视频生成操作手册

更新时间：2026-05-03
适用对象：日常使用飞书多维表格进行 UGC 视频生成的同事
适用范围：UGC-01 至 UGC-07 新链路

---

## 0. 一句话流程

从一个参考视频开始：

1. 在 `UGC-01 视频输入与分析表` 创建任务并填写视频/产品信息。
2. 系统分析视频，派生脚本批次与脚本版本。
3. 在 `UGC-03 脚本版本表` 选择满意脚本。
4. 系统生成 `UGC-04 9宫格分镜图`。
5. 用户审核单张分镜图，不满意可单张重生。
6. 用户确认分镜图后，系统高清化。
7. 用户审核高清图，确认后生成分镜视频。
8. 用户审核分镜视频，不满意可单条重生。
9. 所有分镜视频确认后，再合成最终成片。

核心原则：**每一层都先人工确认，再进入下一层，避免浪费模型成本。**

## 1. 主要表格与用途

| 表格 | 用途 | 用户主要看哪些视图 |
| --- | --- | --- |
| `UGC-01 视频输入与分析表` | 创建新任务、填写参考视频、选择产品 | `01-用户填写入口`、`02-分析结果审核` |
| `UGC-02 分析批次表` | 系统派生批次，通常不用手动操作 | 结果查看/排错视图 |
| `UGC-03 脚本版本表` | 查看和选择脚本版本 | `01-脚本审核选择` |
| `UGC-04 6宫格分镜表` | 生成/重生成 9宫格分镜图 | `01-一键重生成` |
| `UGC-05 分镜图片表` | 审核单张分镜图、高清化、触发视频生成 | `01-分镜图确认`、`02-高清图确认`、`03-分镜视频生成入口` |
| `UGC-06 分镜视频表` | 审核单条分镜视频、单条视频重生 | `04-分镜视频审核与重生` |
| `UGC-07 成片合成表` | 最终拼接成片 | 结果查看/合成入口视图 |

说明：表名里部分字段还叫“6宫格”，但当前业务语义已经升级为 **9宫格容器 + 动态有效镜头数**。日常理解为“9宫格分镜图”即可。

## 2. 创建一个新视频任务

### 2.1 在哪里创建

打开：

- 表：`UGC-01 视频输入与分析表`
- 视图：`01-用户填写入口`

### 2.2 用户需要填写什么

通常只需要填写：

1. 参考视频链接/视频文件相关字段
2. `关联产品`
3. 必要备注，例如目标卖点、风格要求、禁忌点

其中 `关联产品` 很重要：

- 用户只需要在 UGC-01 选择一次产品。
- 后续 UGC-02 / UGC-03 / UGC-04 / UGC-05 / UGC-06 都会继承这个产品信息。
- 不要在下游表里重复改产品，避免链路口径混乱。

### 2.3 如何触发任务

创建/填写完成后，把 UGC-01 入口视图中对应的分析/处理状态设置为系统约定的待处理/待分析状态即可。后台 dispatcher 会自动处理。若入口视图未展示触发状态字段，先不要手动改下游关联表，找负责人确认当前入口视图配置。

日常判断：

- 看到状态进入 `处理中` / `生成中`，说明系统已接手。
- 看到状态为 `成功`，说明当前环节完成。
- 看到状态为 `失败`，需要查看 `错误信息` 或执行结果字段。

---

## 3. 视频分析与脚本版本选择

### 3.1 视频分析结果怎么看

打开：

- 表：`UGC-01 视频输入与分析表`
- 视图：`02-分析结果审核`

重点看：

- 分析状态是否 `成功`
- 分析结果是否符合参考视频内容
- 产品信息是否正确继承
- 是否有明显错误或空结果

如果分析失败：

1. 查看 `错误信息`。
2. 确认视频链接是否可下载/可访问。
3. 确认产品是否已关联。
4. 必要时重新触发分析。

### 3.2 脚本版本在哪里选

打开：

- 表：`UGC-03 脚本版本表`
- 视图：`01-脚本审核选择`

通常系统会生成多个脚本版本。用户需要：

1. 阅读脚本内容。
2. 选择最符合需求的版本。
3. 按当前表格约定把该版本推进到分镜图生成环节。

建议选择标准：

- 产品卖点是否清楚
- 节奏是否适合短视频
- 口播是否自然
- 是否符合目标市场语言与表达习惯
- 是否有明显不该出现的内容

## 4. UGC-04：9宫格分镜图生成与一键重生

### 4.1 这个环节做什么

UGC-04 会把脚本版本转换成 9宫格分镜图。
9宫格只是容器，实际有效镜头数可能是 5、6、7、8 或 9 个。

### 4.2 用户在哪里操作

打开：

- 表：`UGC-04 6宫格分镜表`
- 视图：`01-一键重生成`

### 4.3 重要字段

| 字段 | 谁操作 | 说明 |
| --- | --- | --- |
| `6宫格生成状态` | 系统 | `待生成` / `生成中` / `成功` / `失败` |
| `6宫格图片` | 系统 | 生成后的 9宫格分镜图附件 |
| `一键重生成9宫格` | 用户 | 勾选后，系统会重新生成当前这条 9宫格 |
| `一键重生成状态` | 系统 | `待处理` / `处理中` / `成功` / `失败` |
| `一键重生成结果` | 系统 | 本次重生执行摘要 |

### 4.4 如何重新生成 9宫格

如果整个 9宫格不满意：

1. 找到对应 UGC-04 记录。
2. 勾选 `一键重生成9宫格`。
3. 等待系统处理。
4. 系统会：
   - 重新生成当前 UGC-04 的 9宫格图。
   - 覆盖旧图。
   - 自动重新拆分 UGC-05 单张分镜图。
   - 自动取消勾选 `一键重生成9宫格`。

注意：

- 这是覆盖式重生，不再走旧候选池。
- 重生后，下游单张分镜图需要重新审核。
- 不会自动一路高清化/生成视频，仍需要人工确认。

---

## 5. UGC-05：单张分镜图审核与单张重生

### 5.1 这个环节做什么

UGC-05 是从 UGC-04 9宫格拆出来的单张分镜图。
用户在这里逐张审核，确认每一张是否可以进入高清化。

### 5.2 用户在哪里操作

打开：

- 表：`UGC-05 分镜图片表`
- 视图：`01-分镜图确认`

### 5.3 重要字段

| 字段 | 谁操作 | 可选值/说明 |
| --- | --- | --- |
| `原始裁切图片` | 系统 | 从 9宫格拆出来的单张分镜图 |
| `分镜图审核状态` | 用户 | `待确认` / `通过` / `不通过` |
| `分镜图操作` | 用户 | `不触发` / `确认分镜图并高清化` / `重新生成单张分镜图` |
| `分镜图备注` | 用户 | 可写不满意原因或修改要求 |
| `分镜图执行状态` | 系统 | `待处理` / `处理中` / `成功` / `失败` |
| `分镜图执行结果` | 系统 | 本次处理结果 JSON |

### 5.4 如果单张分镜图满意

对这一行设置：

- `分镜图审核状态 = 通过`
- `分镜图操作 = 确认分镜图并高清化`

后台会自动触发高清化。

### 5.5 如果单张分镜图不满意

比如：

- 人物脸不自然
- 宠物姿势不对
- 产品露出不清楚
- 构图不符合脚本
- 主体不像原来的角色/人物

对这一行设置：

- `分镜图操作 = 重新生成单张分镜图`
- 可选：在 `分镜图备注` 写具体原因

系统会只重绘这一张，不影响其他已经满意的分镜图。

重绘完成后，系统会：

- 更新当前行的 `原始裁切图片`
- 设置 `分镜图审核状态 = 待确认`
- 设置 `分镜图操作 = 不触发`
- 设置 `高清化状态 = 待高清化`
- 清空/复位高清图相关审核动作

也就是说：单张分镜图重生后，需要重新审核，再进入高清化。

---

## 6. UGC-05：高清图审核与重新高清化

### 6.1 用户在哪里操作

打开：

- 表：`UGC-05 分镜图片表`
- 视图：`02-高清图确认`

### 6.2 重要字段

| 字段 | 谁操作 | 可选值/说明 |
| --- | --- | --- |
| `高清化状态` | 系统 | `待高清化` / `高清化中` / `成功` / `失败` |
| `高清分镜图` | 系统 | 高清化后的单张图 |
| `高清图审核状态` | 用户 | `待确认` / `通过` / `不通过` |
| `高清图操作` | 用户 | `不触发` / `生成分镜视频` / `重新高清化` |
| `高清图备注` | 用户 | 可写不满意原因 |

### 6.3 如果高清图满意

对这一行设置：

- `高清图审核状态 = 通过`
- `高清图操作 = 生成分镜视频`

系统会创建/推进 UGC-06，并生成对应分镜视频。

### 6.4 如果高清图不满意

如果原始分镜图 OK，但高清化效果不好，例如：

- 脸部高清化变形
- 产品细节变形
- 画面质感不对
- 局部细节多余/缺失

对这一行设置：

- `高清图操作 = 重新高清化`
- 可选：在 `高清图备注` 写原因

系统会只对当前这一张重新高清化。

如果不是高清化问题，而是原始分镜图本身就不对，应回到 `01-分镜图确认`，使用：

- `分镜图操作 = 重新生成单张分镜图`

---

## 7. UGC-06：分镜视频审核与单条视频重生

### 7.1 这个环节做什么

UGC-06 会把高清分镜图生成单条短视频片段。
每条 UGC-06 对应一个分镜视频。

### 7.2 用户在哪里操作

打开：

- 表：`UGC-06 分镜视频表`
- 视图：`04-分镜视频审核与重生`

### 7.3 重要字段

| 字段 | 谁操作 | 可选值/说明 |
| --- | --- | --- |
| `视频生成状态` | 系统 | `待生成` / `生成中` / `成功` / `失败` |
| `分镜视频` | 系统 | 生成后的视频附件 |
| `分镜视频审核状态` | 用户 | `待确认` / `通过` / `不通过` |
| `分镜视频操作` | 用户 | `不触发` / `生成分镜视频` / `重新生成分镜视频` |
| `分镜视频备注` | 用户 | 可写不满意原因 |
| `分镜视频执行状态` | 系统 | `待处理` / `处理中` / `成功` / `失败` |
| `分镜视频执行结果` | 系统 | 本次处理结果 JSON |

### 7.4 如果分镜视频满意

设置：

- `分镜视频审核状态 = 通过`
- `分镜视频操作 = 不触发`

等所有分镜视频都确认通过后，再进入 UGC-07 成片合成。

### 7.5 如果某一条视频不满意

比如：

- 动作不自然
- 人物/宠物动得不对
- 产品露出变差
- 口型/表情不理想
- 镜头节奏不对

对这一行设置：

- `分镜视频操作 = 重新生成分镜视频`
- 可选：在 `分镜视频备注` 写原因

系统会只重跑当前这一条 UGC-06 视频，不影响其他分镜视频。

重生成功后，系统会：

- 覆盖当前行的 `分镜视频`
- 更新本地视频路径 / file_token / URL / 任务 ID
- 设置 `视频生成状态 = 成功`
- 设置 `分镜视频审核状态 = 待确认`
- 设置 `分镜视频操作 = 不触发`
- 设置 `分镜视频执行状态 = 成功`

注意：不会自动重跑 UGC-07 成片合成。

## 8. UGC-07：最终成片合成

### 8.1 什么时候合成

建议在以下条件都满足后再合成：

1. 所有需要的视频片段都在 UGC-06 里生成成功。
2. 所有 UGC-06 分镜视频都已人工确认。
3. 不再需要单条视频重生。

### 8.2 成片音频口径

当前 UGC-07 的正确口径：

- 使用 UGC-06 / Veo 生成的视频原始音轨。
- UGC-07 只做拼接。
- 不做 TTS。
- 不替换口播音频。
- 如果个别源片段缺音频，最多补静音轨用于拼接一致性。

## 9. 后台触发器说明

用户不需要手动运行脚本。后台有本地轮询器自动处理任务。

### 9.1 9宫格一键重生触发器

- 名称：`com.ryan.ugc-one-click-reroll`
- 扫描表：UGC-04
- 扫描间隔：每 60 秒
- 触发条件：`一键重生成9宫格 = 勾选`
- 作用：覆盖重生当前 UGC-04 9宫格，并同步刷新 UGC-05 单张分镜图

### 9.2 分镜图/高清图审核触发器

- 名称：`com.ryan.ugc-review-trigger`
- 扫描表：UGC-05
- 扫描间隔：每 60 秒
- 触发条件：
  - `分镜图操作 = 确认分镜图并高清化`
  - `分镜图操作 = 重新生成单张分镜图`
  - `高清图操作 = 生成分镜视频`
  - `高清图操作 = 重新高清化`
- 作用：处理单张分镜重绘、高清化、重新高清化、创建/生成分镜视频

### 9.3 分镜视频重生触发器

- 名称：`com.ryan.ugc-video-review-trigger`
- 扫描表：UGC-06
- 扫描间隔：每 60 秒
- 触发条件：
  - `分镜视频操作 = 重新生成分镜视频`
  - `分镜视频操作 = 生成分镜视频`
- 作用：只重跑当前这一条 UGC-06 视频

## 10. 常见状态怎么看

### 10.1 状态字段

一般状态含义：

| 状态 | 含义 |
| --- | --- |
| `待生成` / `待处理` / `待确认` | 等待用户或系统处理 |
| `生成中` / `处理中` / `高清化中` / `裁切中` | 系统正在处理，请等待 |
| `成功` | 当前环节完成 |
| `失败` | 当前环节失败，需要看错误信息 |
| `通过` | 用户确认通过 |
| `不通过` | 用户确认不通过 |
| `不触发` | 当前没有需要系统执行的动作 |

### 10.2 操作字段

操作字段是“按钮式入口”。用户只在需要触发系统动作时选择它。

处理完成后，系统通常会自动把操作字段复位为：

- `不触发`

如果某条记录长时间没有动：

1. 检查操作字段是否真的选择了触发动作。
2. 检查对应审核状态是否满足要求。
3. 检查执行状态是否为 `失败`。
4. 查看错误信息或执行结果。

## 11. 常见问题处理

### Q1：我点了操作，但系统没反应怎么办？

先等 1-2 分钟，因为后台每 60 秒扫描一次。

如果仍没反应：

1. 检查是否选错表/视图。
2. 检查操作字段是否为正确动作，而不是 `不触发`。
3. 检查审核状态是否满足条件。
4. 查看执行状态和执行结果。

### Q2：单张图不好，是重生 9宫格还是单张分镜图？

看问题范围：

- 整体分镜逻辑都不满意 → UGC-04 勾选 `一键重生成9宫格`
- 只有某一张图不好 → UGC-05 设置 `分镜图操作=重新生成单张分镜图`
- 图本身 OK，但高清后变差 → UGC-05 设置 `高清图操作=重新高清化`
- 视频动作不好，但图没问题 → UGC-06 设置 `分镜视频操作=重新生成分镜视频`

### Q3：重新生成单张分镜图后，高清图还能继续用吗？

不能。系统会自动把高清化状态退回，要求重新审核和高清化。

原因：原始分镜图变了，旧高清图不能继续作为下游依据。

### Q4：重新生成单条分镜视频后，会自动更新成片吗？

不会。
UGC-06 单条视频重生后，UGC-07 成片需要等所有分镜视频确认后再重新合成。

### Q5：同事可以同时操作多条记录吗？

可以，但建议分批操作，尤其是高清化和视频生成会调用真实模型，有成本和等待时间。
日常建议：先确认 1-2 条试跑效果，再批量推进。

## 12. 推荐日常操作顺序

### 新任务

1. UGC-01 创建任务并关联产品。
2. 等待视频分析成功。
3. UGC-03 选择脚本版本。
4. 等待 UGC-04 生成 9宫格。
5. UGC-05 审核单张分镜图。
6. 分镜图通过后触发高清化。
7. UGC-05 审核高清图。
8. 高清图通过后触发分镜视频生成。
9. UGC-06 审核分镜视频。
10. 所有分镜视频通过后，进入 UGC-07 合成。

### 修改/返工

- 整体分镜不对：UGC-04 一键重生成 9宫格。
- 单张分镜图不对：UGC-05 重新生成单张分镜图。
- 高清图不对：UGC-05 重新高清化。
- 单条视频不对：UGC-06 重新生成分镜视频。
- 成片不对：先确认是哪条 UGC-06 片段有问题，修完后再重新合成。

---

## 13. 不建议手动改的字段

为了避免链路错乱，以下字段一般不要手动改：

- 各类 file_token 字段
- 本地路径字段
- 系统任务 ID 字段
- 原始响应 JSON 字段
- 系统执行结果 JSON 字段
- 关联记录字段，除非明确知道上下游关系

用户日常主要操作：

- 审核状态字段
- 操作字段
- 备注字段
- UGC-01 的输入字段和关联产品

## 15. 给同事的最短版说明

如果只记住一件事：

> 不满意就不要往下游推。在哪一层不满意，就在哪一层重生。

对应关系：

- 9宫格整体不满意 → UGC-04：`一键重生成9宫格`
- 单张分镜图不满意 → UGC-05：`分镜图操作=重新生成单张分镜图`
- 高清图不满意 → UGC-05：`高清图操作=重新高清化`
- 单条视频不满意 → UGC-06：`分镜视频操作=重新生成分镜视频`
- 满意才设置审核通过，并触发下一环节。
